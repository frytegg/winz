# Run of show

Minute by minute. Written before rehearsal, updated after the demo audit, rehearsed from
with the timer running on the machine you will present from.

**Format:** _N_ minutes presentation + _N_ minutes Q&A. Slide cap: _N_.

## Before you walk up

| | |
|---|---|
| Pre-flight | `bash preflight.sh` — green, and the demo state check passed |
| Browser | one window, the demo tab open, zoom set, nothing else in the tab strip |
| Machine | operating system activated, notifications off, projector side known |
| Memory | measured, above the floor |
| Demo data | not expiring during the slot |
| On a second device | this file and the hard-questions file |
