# Debrief

Within 24 hours of the result, before anyone has told the story twice. Ask the people who were in the room
and write their answers verbatim, with who said it. `10-calibration.md` cannot calibrate on anything that is
not here.

**Event:** _name, date, track_ · **Result:** _place, prize_ · **Field:** _projects in the track, in the event_

| # | Question | Answer, verbatim |
|---|---|---|
| 1 | What did the jury actually see: video, live, slides? How long? | |
| 2 | What was cut on the day, and why? | |
| 3 | Did a juror touch the demo? Was it allowed? | |
| 4 | Who judged, by role? Which of them had we met before as mentors? | |
| 5 | What did they ask, in order? | |
| 6 | What did they say afterwards, in their words? | |
| 7 | Was the business model said, and with figures or only the mechanism? | |
| 8 | Which surfaces were judged outside the pitch: a table visit, the repository, the form? | |
| 9 | What did the winners of the other tracks build? Link to the announcement. | |
| 10 | What would you cut or add if you pitched it again tomorrow? | |

Then write the base-rate row into `references/10-calibration.md`, count the winners
(`references/09-previous-rounds.md`), and only then draw a lesson.
