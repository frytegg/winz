# Rehearsal Hack — organiser brief (fictional)

This event does not exist. It gives the rehearsal of /execution an event profile to read, with the same kinds of
rules a real hackathon has. Times are UTC; the profile displays them in SGT and Paris.

## Schedule

- Kickoff (T0): {{t:t0}}
- Submission deadline: {{t:end}} (repository link, recorded video, form)
- Judging: on stage right after the deadline, from the recorded video and the repository

## Rules

1. Existing code and data may be brought. Designs, mock-ups, logos and visual explorations must be made after
   kickoff.
2. The video is at most 180 seconds, 1920x1080, submitted as an mp4 file.
3. No live demo on stage: the recording is what the jury sees.
4. Any statement of a partnership with a protocol must be backed by that protocol in writing.

## Rubric (single track "main")

| criterion | weight |
|---|---|
| Technical depth | 30 % |
| Usefulness to the sponsor's users | 30 % |
| UX & Design | 20 % |
| Presentation | 20 % |

## Deliverables

- Repository link (public at the deadline, or shared with the judges)
- Recorded video (mp4)
- Submission form
- A tag on the submitted commit
