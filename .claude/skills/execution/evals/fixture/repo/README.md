# Queue Clock

A dated range for a withdrawal request in a liquid-staking queue, from the queue's own numbers.

This repository is the product side of a rehearsal fixture. At instantiation it holds only frozen, synthetic data
under `data/` (see `data/README.md`); the engine, the command line and the page are built during the rehearsal.
Every figure in it is synthetic and describes no real protocol.
