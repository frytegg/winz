### FD15-F02 — Anthropic's diagnosis is "distributional convergence": without direction, Claude samples the high-probability centre of web design
- **Grade:** A · **Kind:** ASSERTED · **Verdict:** VERIFIED

The shared prompt opens with the same idea, addressed to the model in the second person ("on distribution"). The blog frames the fix as a general method: "identify convergent defaults, provide concrete alternatives, structure guidance at the right altitude, and make it reusable through Skills." The claim comes with no data.
- **Implication for /frontend:** The owner's 20 tells are symptoms of sampling toward a centre. A blocklist moves the centre but does not remove it (F03). To get off-centre, the skill has to feed the model inputs that are specific to the project: the protocol's own vocabulary, the /hackathon research on sponsors and their customers, and the customers' sites. Those inputs should be treated as the design's raw material, not decoration.

### FD15-F06 — v3 typographic and structural tells: one-word accents, all-caps labels, labels above content, 01/02/03 markers, the big-number hero
- **Grade:** A · **Kind:** OBSERVED · **Verdict:** VERIFIED

- **Implication for /frontend:** Rules to add or sharpen:

  - numbered markers where the content is not a sequence;
  - a hero built as big-number-plus-stats.

### FD15-F33 — Anthropic's claude.ai system prompts: Claude does not reproduce a specific logo, app icon set or product design, even drawn in code (added at verification)

### Where Anthropic's own guidance could produce the next cliché

- **Published font lists.** Of the cookbook's "Impact choices" (Space Grotesk, Playfair Display, Fraunces, Clash Display, Satoshi, Cabinet Grotesk, Bricolage Grotesque, Newsreader), Fraunces and Playfair were named within a year as part of Opus 4.8's house style, and Fraunces as overused (F12). No source establishes causation, but any font list in /frontend risks the same fate.
- **"Pair a distinctive display font with a refined body font" and "serif + geometric sans."** This recipe matches the display-serif plus grotesk look (#19) and sets up the serif italic accent (#18). v3 answers it with "use one family or two, and if two, make them clearly distinct".
- **"Use extremes: 100/200 weight vs 800/900 … Size jumps of 3x+."** A likely source of the giant hairline or ultra-black headline. Not named as a tell anywhere yet (inference).
- **"Create atmosphere and depth rather than defaulting to solid colors … Layer CSS gradients."** This is still in the platform guide (PB). It invites gradient washes and grain (#20) and translucent layers (#6).
- **"Draw from IDE themes."** An easy path to cluster 2 (near-black with an acid accent).
- **"One well-orchestrated page load with staggered reveals."** When every page gets its one orchestrated moment, the moment becomes the cliché: the hero load-in sequence (inference).
- **"Spend your boldness in one place" and v2's "Signature."** Well meant, but it may converge on one oversized gimmick per hero: a 3D object, a giant numeral, an animated diagram (inference, not documented).
- **"Accents: 0–2, in oklch, sharing chroma and lightness" (CR).** A sound method that could converge on the same harmonised duotones across projects (inference).
- **"Inline stroke SVG" as the fallback icon style (DT).** That is the Lucide look (#10).
- **The ban lists themselves.** Anthropic says a generic ban "mostly swaps one default for another" (F03). Each named hex pushes the model to the nearest un-named neighbour, so the checker must be re-run and extended.
- **Examples inside instructions.** The earlier Design type release demonstrated its file format with a Georgia-on-`#faf9f5`, `#d97757`-accent, 12 px-radius, accent-bordered card example (F31). Any worked example /frontend ships will leak its look the same way.
- **Rubric wording.** Anthropic's own design harness found that a criterion phrased "the best designs are museum quality" pushed designs toward "a particular visual convergence" (F32). The /frontend grader's rubric is an input like any template and needs the same regression test. (added at verification; documented, not inferred)
